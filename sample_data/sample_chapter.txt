Machine learning is a field of artificial intelligence that enables computer systems to identify patterns in data and make predictions or decisions without being explicitly programmed for every possible case. A machine learning workflow often begins with collecting and cleaning data, selecting useful features, splitting the data into training and test sets, training a model, and evaluating the model on data it has not seen before.

Supervised learning uses labeled examples. Classification predicts categories, such as whether an email is spam, while regression predicts numeric values, such as a house price. Unsupervised learning works with unlabeled data. Clustering groups similar observations, while dimensionality reduction represents data with fewer variables while attempting to preserve important structure.

Overfitting happens when a model learns noise or details specific to the training data and performs poorly on new examples. Underfitting occurs when a model is too simple to capture useful patterns. A validation set can help compare model settings, while a separate test set is used for a final estimate of generalization. Data leakage occurs when information that would not be available at prediction time accidentally influences training or evaluation, resulting in misleadingly strong performance.

Common classification metrics include precision, recall, and F1 score. Precision measures the fraction of predicted positive cases that are actually positive. Recall measures the fraction of all actual positive cases that the model successfully identifies. The F1 score is the harmonic mean of precision and recall. Accuracy can be misleading on imbalanced datasets, so a metric should be selected based on the task and the cost of different errors.
